# brant-skills

给 Brant(布布)本人用的 AI 技能。它把你 2020-08 到 2026-11-11 的直播、喊单、文字线整理成可以查、可以检验的记录,装进 Codex 或 Claude Code 后直接用中文提问。

> 私有仓库。里面是直播逐字稿和原话,请不要公开或转发。

## 有什么用

- **查当时为什么**:某笔买、卖、换仓、不买,当时的原话和理由是什么,后来怎么处理的。
- **看哪类做法赚钱**:按买入理由、行情、年份、仓位大小分组的成绩单;说「不买」准不准;清仓和减仓哪个有用;扛单的代价。
- **看一只票的全貌**:看法怎么变、每段持仓的结果、复盘里怎么说、还没了结的预设点位。
- **对照老毛病**:35 类你自己承认过的失误,哪些数据确认有代价,哪些其实看不出。
- **搜原话**:890 场直播逐字稿和全部喊单,全文搜索。
- **写长文**:把某段时期或某只票的操作和心路历程写成文章,每句原话带出处并自动核对。
- **按关键词找理念**:「我对止损是怎么说的」,先找到相关的几条理念,再看每条的原话和演变。
- **记更正**:哪里记错了,说一句就记下来,回流给整理者改。
- **接券商(可选)**:接了长桥、IBKR 或 Robinhood 的话,只读地把现在的持仓和历史记录对一遍;也能取行情,看预设的价位到了没有、给文章配走势图。

它**不给现在的买卖建议,也不帮你筛股票**;记录来自展示账户喊单和直播,不是实盘;数据定格在 2026-11-11,不会自己更新。

## 怎么用

需要 Python 3.8 以上,不用装别的东西。

1. `git clone` 这个仓库。
2. 用 Codex 打开这个文件夹,直接提问。第一次可以问:**「这个技能能做什么」**。
3. 建议先看两样:问「给我看一页结论」和「数据有哪些已知问题」。

想在别的文件夹也能用,或者用 Claude Code:把 `.agents/skills/brant-why` 整个文件夹复制到用户目录下的 `.agents/skills/`(Codex)或 `.claude/skills/`(Claude Code)。

## 发现记错了

直接说「E03882 这笔不对,实际是 TSLL」,它会记到仓库根目录的 `brant-feedback.jsonl`。数据不会马上变:把这个文件提交推送或发给整理者,改完源头重新导出后才更新。

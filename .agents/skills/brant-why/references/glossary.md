# CONTEXT — brant-lens 术语表

把 chinesefn.com 美股 VIP 直播间分析师 **Brant**(观众称"布布老师/布帅",userId=6)三年的判断方式,蒸馏成一个可移植的 AI 技能。本文件定义项目里的术语;新会话、子 agent 都按这里的含义理解。

## 人与来源
- **Brant**:目标人物。注意"雷公"不是 Brant(直播里被引用的第三人);学习区"作者=Brant"只是上传者,不代表讲者(《缠论看美股》实测不是他)。
- **喊单(call)**:`/service/live/transaction/record` 里他正式发布的操作或观点。来自他的**展示账户**(2025-07-11 自述"这个 Robinhood 账户就是我的引流成本"),方向与理由可信,规模只作相对参考。
- **聊天(chat)**:`/service/live/discuss/query` 里他在直播间的随口发言。
- **回放(playback)**:直播录像,YouTube unlisted 链接;一天可能多段,上传者 ≠ 讲者。
- **教学视频(lecture)**:`/service/study/query`,只有声纹确认是他讲的才用。

## 处理对象
- **日内交易**:当天开平的期货/超短线,以及自营考核账户(闯关/通关/PA/apex/tradeify/topstep/Lucid/MFF)操作。**一律排除**(用户要求),但他借日内行情讲的通用方法可抽成理念。
- **声纹(voiceprint)**:`voiceprints/{2026,2023}.npy`,分年代;各自阈值见 `speaker_map.py` 的 `PRINT_THR`。
- **卡片(card)**:子 agent 从原文抽出的结构化条目,`quote` 必须是原文逐字存在的原话。

## 卡片类型
- **理念(rule / philosophy)**:他明确说出或反复体现的通用方法。**不以有喊单为前提**。
- **观点(view)**:对大盘/利率/板块/个股的方向判断,会过期。
- **仓位事件(position / trade)**:一段完整持仓(开→加→减→平)或一次具体操作。
- **复盘(review)**:他对自己赚/亏的总结。
- **自我修正(self_correction)**:他承认的瑕疵/失误/老毛病 + 他说的正确做法。
- **时期小结(period / summary)**:一季或一场的基调。

## 审核用语(阶段 4)
- **有效期状态**:`持续`(三年反复一致)/ `演进`(说法变了,旧版→新版)/ `过时`(不再提或被后来行为推翻)/ `情境化`(看似矛盾,实则条件不同)。
- **裁决优先级**:他本人后来的明确修正 > 近期一致的实际行为 > 出现频次。
- **言行不一**:说的规则与仓位事件矛盾(如"MSTR 除外")。
- **原版 vs 修正版**:技能里并列;修正版优先取他自己的教训,其次取战绩数据,不是他原话的必须标"改进建议,非 Brant 原话"。
- **行情状态**:牛市趋势 / 牛市回调 / 震荡 / 熊市 / 急跌 / 反弹。
- **盲区**:他反复出现、会导致亏损的思维/行为模式,技能调用时必须检查。

## 战绩检验用语(阶段 3)
- **检验维度**:战绩分四个维度各自判定,不合成一个总分。
  - **大方向(择时)**:对大盘多空的判断事后对不对。
  - **选股(入场)**:他买入的标的之后是否跑赢基准。
  - **离场时机**:他卖出之后,该标的是否真的走弱。
  - **逆境持仓**:持仓浮亏触及止损线后他继续持有(俗称「硬扛」),比起当时止损是赚是亏。
- **不检验**:仓位/风控规模——喊单来自展示账户,规模不代表实盘。
- **跟单者视角**:用户本人账户跟随他操作的实际结果;只作描述,不参与判定 Brant 有无优势。
- **主检验**:每个维度事先指定的唯一一个(指标+期限+基准),只有它能给出判定。
- **探索性结果**:主检验以外的一切计算(其他期限、其他基准、分层);照常报告,但不改变判定。
- **判定三档**:`有证据显示优势`(区间下限 >0)/ `有证据显示劣势`(区间上限 <0)/ `无定论`(区间跨 0 或样本不足,须注明是哪一种)。
- **修订版检验**:判定口径事后发现有问题时另起的检验,与原版并列报告并注明事后补充;原版不改。
- **战绩行情分档**:给战绩分层用的 QQQ 机械口径(牛/熊/震荡),按决策当天判定;与上文「行情状态」(他口中的 6 种描述,抽卡用)不是一回事。
- **待验证假设**:分层里冒出的突出发现;不能直接写成技能建议,须经前瞻测试通过才可升格。
- **判定样本 / 留出样本**:2026-06-30 及以前的决策是判定样本,结果可进技能;之后的决策是留出样本,操作结果只进报告、不进判定。**理念卡不受此限**:技能用全部卡(含 2026-07 以后)并随新直播持续更新(4.4 J12;默认每周一次,改口先交用户判断,J35),所以 2026-07 以后不再是干净的技能测试集,阶段 6 以前瞻存档为主。
- **确认在扛**:持仓触及止损线后,有证据表明他仍持有(之后才明确卖出,或之后又以持有/加减仓/复盘提到它)。只有确认在扛的触发进逆境持仓的主检验;触发后再没提过的记为「未知」,只做上下界敏感性分析。
- **预检后修改**:预注册定稿前,只看样本量(不看收益)发现口径问题时做的修改;每个维度最多一次,须写明原因。
- **决策事件**:一次原子决定(开仓/加仓/减仓/清仓/持有表态/回避/观望),同一天同一标的同方向同类动作在喊单、文字线、直播里出现多次的合并为一个事件。是阶段 3-6 的共同底座(`data/events.jsonl`)。
- **持仓段**:同一标的同方向的开仓、加仓、减仓串起来的一段持仓,明确清仓即结束;距上次开/加仓超过约 20 个交易日的再买算新的一段。选股/离场/逆境持仓的样本单位(`data/positions.jsonl`)。
- **价格口径**:`实价`(喊单/文字线写明的成交价,已换算到复权口径)/ `收盘近似`(直播当天美东收盘)/ `近似`(期权,按正股收盘)/ `条件单成交`(按限价单规则成交)/ `无`(缺价格)。
- **条件单**:「跌到 X 再买」「X 以下买」「突破 X 就进」这类以价位为前提、说话时尚未满足的买入;按限价单处理,10 个交易日内收盘触及才算入场。没触及的叫**未成交条件单**,不算入场,单列。
- **回顾性提及**:直播里讲以前做过的交易(教学举例、解释前几天的买入),不算当天的新决定。

## 理念台账与失误用语(阶段 4)
- **理念台账**:**现行 = v2 `data/ledger_v2/ledger.jsonl`**(2026-10-26 用户拍板替换;v1 `data/ledger/` 存档,预注册检验结果 tests.json 仍在 v1 目录)。一条理念一行;≥3 张卡且 ≥2 场的进台账(`tier=ledger`),其余为**长尾**(`tier=tail`),不删。编号见 `docs/rule-catalog.md`(由 `make_rule_catalog.py` 从 v2 生成;v1 目录存档 `docs/rule-catalog.v1.md`),阶段 4 新增两族 **T**(技术指标/图形)、**R**(风控/止损)。
- **证据等级**:A = 言行一致(当场有对应操作且经核对 ≥3 场,多于反证)/ B = 只有言论 / C = 言行相反(反证 ≥3 且不少于一致)。有原版 `grade` 与修订版 `grade_v2` 两种口径(ADR-0007 附录);**技能先用修订版 `grade_v2`**(4.4 J5)。A 只说明言行一致,不说明理念有效;C 是「他的核心规则,但他自己常违反」,不等于规则错;只有失误聚类能指向的 38 个旧目录编号可能被判 C,新编号理念不会出现 C。
- **言行一致实例**:同一场直播里,他说某条理念前后 10 分钟内的真实操作,经核对确实体现了这条理念。
- **反证**:他承认违反某条理念的自我修正卡,或当场言行相反的操作。
- **可指标化 / 可清单化 / 仅背景**:理念能否写成可执行规则——条件能直接用行情数据(价格、均线、成交量、VIX、指数)机械判断的为可指标化;能写成调用技能时问的是/否问题的为可清单化;都不能的只作解释。基本面阈值、期权下单规则、他的私有 AI 指标一律不算可指标化。
- **单条回测**:对一条理念做的预注册检验(ADR-0007 T1-T7),通过 = Holm 校正后 p <0.05 且方向支持理念。
- **失误类型**:他承认的同一种可复发行为模式,编号 B1-B35(B1-B8 沿用旧目录,B9 起为阶段 4 聚类新增),定义在 `data/ledger/merge/mistakes.out.json`。
- **再犯检测**:用交易记录机械识别某类失误是否又发生(ADR-0007 K1-K13);K1-K5 有代价指标,K6-K13 只作描述。
- **本人做法 / 给听众的规则**:同一条理念里,他自己的做法(如常年满仓满融)与他对听众说的规则(如驾驭不了别用、留余量)可能不同。技能默认用**给听众的约束性规则**;本人做法单独标「他本人做法(自述,实盘规模无法核实)」;给听众的**鼓励类**说法(如「不要怕用杠杆」)只作描述(4.4 J6)。
- **自评与数据错位**:他自我批评最多的失误(硬扛、卖飞、空早、抄早)在数据里大多看不出代价,数据显示的弱项(选股、大赚后追回、追涨、损耗型工具拿太久)他提得少。修正版以数据为准,不照他的自我反省反向操作(`skill/references/corrections.md`)。分档(4.4 J9):数据已判定的给结论;跨 0 或探索性的并列写出、标「待验证假设」;两种都同时写出他的原话和数据。
- **运行后修正**:检验跑完后发现的实现错误(不是口径变更),按原定义修正并保留原输出,写进对应 ADR 附录。

## 三、主要结果

### 1. 台账(已判 289 条)
- 有效期:持续 200、演进 44、情境化 30、过时 15。过时的多是 2021-2022 教学期的技术指标用法(TD 九转、K 线组合、期权大单)和被他后来推翻的说法(如「议息前先涨是利好」)。
- 证据等级:原版 A 40 / B 219 / C 30;修订版 A 53 / B 218 / C 18(口径问题见 ADR-0007 附录)。修订版 C 级是他讲得最多的核心规则——D1 大方向、D9 不空新高、E1/E4 进场、M1 按计划、M2 认错点、P3 单票上限、S1 能力圈、H3 做空用 put——**他最常讲的规则,也是他最常承认违反的**。
- 可执行格式:可清单化 232、可指标化 54、仅背景 3。
- 熊市覆盖:已判 289 条里 57 条从未在熊市档出现过(标「未经熊市检验」)。

### 2. 单条回测(T1-T7,Holm 校正,预注册)
**没有一条通过。** T1(买入时他自己看多大盘)+5.7 个百分点、原始区间不跨 0,但校正后 p=0.065,且属已见过的分层;T2(左侧买入)+4.8 个百分点,跨 0;T3、T5、T7 无定论;T4(VIX≥30)、T6(均线空头排列)独立段不足 15,样本不足。
含义:54 条「可指标化」理念目前**没有一条有数据背书**,进阶段 5 的信号脚本只能标「未检验」,靠阶段 6/7 前瞻测试。

### 3. 失误与修正(详见 `skill/references/corrections.md`)
**自评与数据错位**:他自我批评最多的(B5 硬扛 56 张、B9 卖飞 70 张、B12 空早 52 张、B15 抄早 41 张)在数据里大多看不出代价,有的还是他的长处(C 离场、D 硬扛);数据确认的弱项是:
- 选股:个股买入 12 周平均跑输 QQQ 3.5%(B 主检验)。他自己的规则 S13 说「拿捏不准时做指数」,但趋势确认后转回个股那一步同样跑输。
- **B2 大赚清仓后追高买回**:20 次,12 周跑输 QQQ 12.4%,区间 [−20.6%, −4.4%]——他只自承过 4 次。
- B16 损耗型工具做空拿太久:2023-10 起 11/23 段持有 >5 天,工具本身平均 −20.5%。
- B14 浮盈不减、吐掉过半:42 次,26 次转亏;B21 震荡里来回反手:20 次——都还在犯(最近 2026-06 ~ 08)。

## 四、局限(必须照写)
- **聚类准确率约 80%**(主会话抽查 20 张:16 张准确、4 张偏松);判断 agent 也发现部分同义卡没归进对应理念(S20、S37、S38、X16),所以频次、首次/最近日期是近似值,「过时」判定已逐条回查原话。
- 言行一致只能用直播卡(文字线 rule 卡没有 `has_call`);一条理念最多核 8 对。
- 证据等级的不对称:新编号理念不可能有「违反」卡,C 级只会出现在旧目录规则里。
- K2(亏损称止盈)机械检测不可靠,只保留有价格佐证的个案。
- **持仓段配对假象**:2023-10 以前开仓、无卖出记录的持仓,会被之后一笔无关的卖出「关掉」(K11 发现)。这不影响 B(固定 12 周)和 C(看卖出事件本身),但**可能影响 D(硬扛)里 2023-10 以前以「明确清仓」结束的记录**——列为 4.4 待查项,D 判定未改。
- 所有失误检测都是在判定样本(2021-09 ~ 2026-06-30)内;K1 的结论属于已运行的预注册检验,其余 K6-K13 只作描述。
